# DevNest Modern UI / Classic UI Update

- Added persistent Classic / Modern interface modes without changing application features or data.
- Added a quick interface-mode switch in the top bar, a Theme menu selector, and a segmented control in Settings.
- Both interface modes work with every existing System, Dark and Light color theme.
- Added a semantic Modern QSS layer derived from the existing ThemeSpec tokens.
- Improved focus, hover, selected, disabled and primary-action states in Modern mode.
- Added modern developer-tool typography, spacing, surfaces, navigation, inputs, cards, tabs, menus and scrollbars.
- Preserved Classic as the familiar compatibility mode.
- Expanded Turkish/English coverage across interface-mode controls, diagram tools, find bar, note editor, GitHub flows and legacy dialogs.
- Added translation-catalog parity regression coverage and persisted interface-mode settings tests.
- Removed emoji from primary navigation/system controls in Modern mode while preserving Classic behavior.
