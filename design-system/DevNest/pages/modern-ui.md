# Modern UI page rules

- Global navigation: compact rows, readable section labels, accent-soft selected state, visible keyboard focus.
- Top bar: project/search/language/interface-mode/notifications/connectivity remain high-frequency controls without decorative clutter.
- Dashboard and project pages: dense alignment and clear metrics; do not turn every fact into a decorative card.
- Notes/Decisions: preserve editor behavior and code-review workflows; improve focus, title hierarchy and list selection without changing data semantics.
- Settings: interface style is a segmented Classic/Modern control next to the independent color-theme selector.
- Dialogs: reuse active color tokens and preserve native focus/Escape/button behavior.
- Empty/loading/error states: explain what is happening and the next action instead of leaving blank surfaces.
